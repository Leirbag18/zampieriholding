# Zampieri Holding — sito rifatto

Redesign moderno, immersivo e in un unico file `index.html` (HTML/CSS/JS puro, nessuna build) del sito zampieriholding.it.

Tecniche prese in prestito e adattate ai contenuti reali dell'azienda:
- Loader in stile "curtain" con conteggio 000→100 e griglia rem adattiva
- Hero a tutto schermo con parallasse, reveal parola-per-parola, mini-carosello e card statistica
- Carosello "ghost words" per i punti di forza (Qualità / Sicurezza / Presenza costante)
- Lista servizi numerata con hover a freccia
- Card flotta/sedi con tilt 3D al passaggio del mouse
- Sezione Sostenibilità con badge ISO 9001/45001 rotante in 3D (CSS puro)
- Banda statistiche con count-up allo scroll
- Gallery con lightbox
- Modale di contatto/candidatura riutilizzabile, menu overlay a schermo intero

Immagini: foto reali della flotta e delle sedi, ospitate su zampieriholding.it (hotlink verificato). Font: Google Onest. Smooth scroll: Lenis via CDN.

Per vederlo: apri `index.html` in un browser, oppure abilita GitHub Pages (Settings → Pages → Deploy from branch `main` / root).
